# O que oferecer, e quando

## Regra principal: conquiste o direito de pedir

Nunca comece pela oferta. A primeira mensagem existe para começar uma conversa, não para vender. A oferta aparece
quando a pessoa mostrou interesse: respondeu, perguntou como funciona, contou o problema ou perguntou o preço.

## A escada de oferta

Combine a oferta com o quanto a pessoa já se envolveu:

| Momento | Sinal | O que oferecer |
|---|---|---|
| Curiosa | Fez uma pergunta, curtiu, comentou | Responder a pergunta. No máximo: "Tem um vídeo de 2 minutos, quer o link?" |
| Interessada | Contou o problema ("vivo cobrando") | O vídeo ou a página `/conheca`, que mostra as telas de verdade |
| Pronta | Perguntou preço, como começar, se funciona no tablet dela | O link do cadastro: 30 dias grátis, sem cartão, entra com o Google |
| Com pressa | "Começam as férias semana que vem" | O link do cadastro na hora, e ajuda para criar as primeiras tarefas |

## O que temos para oferecer hoje

- **Entrada:** vídeo de 2 minutos (site e YouTube) e a página `/conheca`.
- **Teste:** 30 dias grátis, sem cartão de crédito.
- **Ajuda:** o assistente do painel cria as primeiras tarefas a partir de uma frase.
- **Mais prazo:** em `/admin/assinantes` dá para estender o teste em 7 dias. Use com quem está usando de verdade e
  pediu mais tempo, não como isca.
- **Oferta principal (preço depois do teste):** ainda não definida no app. Preencha aqui quando for.

## Próximo passo sem reunião

O Tarefinha se vende sozinho quando a pessoa vê. Para família, o próximo passo nunca é "vamos marcar uma conversa":
é o link.

- Bom: "Quer o link para testar? Leva uns 5 minutos para criar a conta e a primeira tarefa."
- Ruim: "Posso te apresentar a plataforma?", "Agende uma demonstração".

Para parceiros (escola, clínica), aí sim uma conversa curta faz sentido. Veja `parceiros.md`.

## Linguagem

Diga: "Quer o link?", "Posso te mandar o vídeo?", "Leva uns 5 minutos."

Nunca diga: "Agende uma demonstração", "Eu adoraria te mostrar", "Qualquer coisa me avisa", "Promoção imperdível".
